# Production activity-projection corpus

This corpus pins current production state and projection sources from six
distinct product repositories across declared React DOM, Svelte DOM, React/Ink,
and Rust/Ratatui routes. `authorities.lock.json` is provenance only: semantic
verdict fields are prohibited. `observations.lift.json` is generated from the
exact source bytes by the source-specific parser package.

Two exact upstream selectors produce concrete selection-relative ordered
activity projections whose entries join back to opaque source records. The
other four products statically corroborate that narrower candidate without
being counted as concrete projections. Source extent is explicit because empty
can mean not loaded, summary-only, windowed, or fully empty.
