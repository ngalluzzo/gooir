# Production activity-projection corpus

This corpus pins current production state and projection sources from six
distinct product repositories across declared React DOM, Svelte DOM, React/Ink,
and Rust/Ratatui routes. `authorities.lock.json` is provenance only: semantic
verdict fields are prohibited. `observations.lift.json` is generated from the
exact source bytes by the source-specific parser package.

Two exact upstream branch selectors produce concrete selection-relative
ordered activity projections whose entries join back to opaque source records.
Gemini CLI's exact `useHistory` hook executes under React 19.2.4 and produces a
third concrete projection whose numeric history ids remain projection-local
keys. The exact normal App/layout chain source-binds that state to Gemini's
aliased Ink consumer, without claiming terminal visibility. The other three
products remain static corroboration. Source extent is explicit because empty
can mean not loaded, summary-only, windowed, or fully empty.

Open WebUI is multi-licensed across its history. Its `LICENSE`,
`LICENSE_NOTICE`, and `LICENSE_HISTORY` are all retained. See
`THIRD_PARTY_NOTICES.md` for the remaining pinned license paths.
